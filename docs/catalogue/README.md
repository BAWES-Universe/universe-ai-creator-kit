Neither count means 26 approved playable templates.

## Reading the statuses

Source/byte verification, visual acceptance and live gameplay are separate. A hosted TMJ is a map-loading URL, not an authenticated Universe room. No play-room URL is invented. Public GitHub links were checked against pinned repository trees; hosted URLs retain their dated publication-receipt checks. Library artifacts are private to their owner. Missing originals and active-work gaps are explicit.

No asset license is added by this catalogue. Preserve source attribution and check original asset rights before reuse or redistribution.

## Add the next iteration

Keep the same family ID. Give each reviewable revision a new stable ID and version, point to its parent, and append dated feedback rather than overwriting it. Keep rejected versions available. Record preview, editable source, hosted map/room link when real, source hash, provenance, and the next test. Mark unknown values explicitly. An artifact is not accepted merely because it was generated or its schema passed.

Recommended home: `universe-ai-creator-kit/docs/catalogue/`. Runtime maps and asset originals remain in `universe-maps` or their existing Library archives. Update this catalogue with each new reviewable map/Woka; update the handbook only for reusable lessons. Source/preview URLs should be commit-pinned; host URLs must retain a last-checked date. Never relabel old screenshots as fresh gameplay captures.
